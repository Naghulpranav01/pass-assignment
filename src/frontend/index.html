Architectural Distinction: Why JTAG is a Debug Interface, NOT a Compute Board

A JTAG debug adapter (such as a SEGGER J-Link or FTDI FT2232H) is fundamentally an external test access port (TAP) master operating under the IEEE 1149.1 standard. It does not execute application compute workloads, host general-purpose operating systems, or exchange application data packets with the host. Instead, it senses target rail voltage ($V_{\text{REF}}$), drives synchronous clock ($TCK$) and state select ($TMS$), shifts bitstreams in/out of boundary-scan registers ($TDI$/$TDO$), and controls active-low reset lines ($nSRST$/$nTRST$). Assuming all boards share a single connector, voltage domain, or communication protocol would risk catastrophic electrical overstress (e.g. driving 5V logic into a 1.0V/1.8V FPGA bank).
